# Harry's Web Page

A plain HTML, CSS and JavaScript starter site for `harryswebpage.co.uk`.

## Pages

- `index.html` — intentionally blank homepage beneath the shared header and navigation
- `projects.html` — placeholder Scratch portfolio
- `videos.html` — placeholder stop-motion portfolio
- `blog.html` — blog index
- `posts/` — two placeholder blog posts
- `css/styles.css` — shared black-and-white styling
- `js/main.js` — ready for later interactive features
- `images/` — place website images here

## Previewing the website

Open `index.html` in a browser, use the VS Code Live Server extension, or run this command from the project folder:

```sh
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publishing

Copy the contents of this folder into the root of the GitHub repository. GitHub Pages will treat `index.html` as the homepage.
